# Електросервіс

Самостійний статичний сайт українською та англійською мовами. Звичайні HTML, CSS та JavaScript без фреймворків, зовнішніх скриптів, аналітики чи шрифтів із CDN. Python 3.11+ потрібен для генерації, збірки й локального сервера. Node.js 22+ використовується для перевірок.

## Запуск і збірка

```sh
npm ci
npm start
npm run generate
npm run build
```

`npm start` запускає локальний сервер на порту 8000. Для іншого порту: `python3 scripts/serve.py --port 8001`. Сервер враховує маршрути й заголовки `netlify.toml` та віддає власну сторінку 404.

`npm run generate` оновлює HTML у корені репозиторію та `en/` після змін генератора чи текстів. `npm run build` генерує публічну версію в `dist/`, копіює тільки ресурси сайту та перевіряє локальні посилання. Netlify виконує таку саму збірку й публікує `dist/`. Залежності, тести, архіви й звіти не публікуються.

## Структура

- `scripts/generate.py` — спільна семантична розмітка сторінок.
- `content/translations.json` — українські та англійські тексти.
- `content/products.json` — усі 17 товарних позицій із технічними описами. Технічні документи українською також доступні в англійській версії з позначенням мови.
- `assets/site.css` — адаптивні стилі, фокус, підтримка зменшення анімацій.
- `assets/site.js` — мобільне меню, фільтри каталогу, галерея та легкі анімації.
- `assets/contact.js` — валідація й відправлення форми, захист від повторних запитів та тайм-аут.
- `assets/*.webp` — оптимізовані локальні фотографії й логотипи.

Фотографії товарів, яких не було серед локальних ресурсів, не підмінено фотографіями інших моделей: каталог показує назви та збережені технічні характеристики. Фото виробництва й реалізованих проєктів доступні окремо.

## Перевірки

```sh
npm test
npm run test:e2e
npm run audit
```

Браузерні тести автоматично запускають сервер на порту 8001 і перевіряють три розміри екрана: 1440×1000, 768×1024 та 390×844. Покрито мови, навігацію, клавіатуру, каталог, галерею, форми, доступність через axe, 404 і контрольні скриншоти. Зовнішні запити блокуються, а сервіс форм підмінюється: жодні реальні повідомлення не надсилаються.

Якщо `/usr/bin/chromium` відсутній, встановіть браузер командою `npx playwright install chromium` або задайте `CHROMIUM_PATH`. На Linux можуть знадобитися бібліотеки з `npx playwright install-deps chromium`.

Еталони зображень лежать у `tests/browser/site.spec.cjs-snapshots`. Після навмисної візуальної зміни перегляньте зображення й виконайте `npm run test:visual`. Еталони залежать від ОС, браузера та системних шрифтів.

Lighthouse запускайте окремо від інших браузерних тестів. Звіти зберігаються в `artifacts/lighthouse.html` і `artifacts/lighthouse.json`. Аудит сам запускає сервер на порту 8002; за потреби можна передати `AUDIT_URL`. Локальний сервер не відтворює CDN і стиснення хостингу, тому показники опублікованого сайту можуть відрізнятися.

## Зовнішні інтеграції

Під час перегляду всі ресурси завантажуються з цього сайту. FormSubmit отримує дані тільки після підтвердженого надсилання форми. Карта Google та каталог Google Drive відкриваються лише після натискання відповідного посилання. Доставка повідомлень до поштової скриньки — окрема інтеграційна перевірка.
